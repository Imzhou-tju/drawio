# drawio

一个用来存放和整理 draw.io 图的仓库。

## 仓库内容

- 业务流程图
- 架构图
- 思维导图
- 项目规划图
- 学习笔记图

## 按主题补充一些内容

### 1. 学习主题

- 数据结构与算法
- 计算机网络
- 操作系统
- 数据库原理

### 2. 项目主题

- 前端页面结构
- 后端接口流程
- 登录鉴权链路
- 部署与发布流程

### 3. 生活主题

- 旅行计划
- 读书清单
- 健身打卡
- 时间管理

### 4. 灵感主题

- 个人知识体系
- 年度目标拆解
- 团队协作流程
- 产品功能脑图

## 使用建议

你可以把不同主题的图分别放在对应目录里，文件名尽量清晰，方便后续查找和复用。
